# AI İndirme Köprüsü — Tasarım Spec'i

> Vizyon: Tüm AI'ların (Kimi, Claude, Gemini, Open Interpreter...) indirme işlerini
> tek noktadan yöneten, kullanıcının mini pencereden görüp kontrol ettiği açık kaynak
> masaüstü aracı. AI link verir — gerisini tool halleder.

## 1. Kilitli Kararlar
| Karar | Seçim |
| --- | --- |
| Mimari | Tek Kapı: tool kendi localhost uç noktasını açar, tüm AI istekleri oradan geçer |
| Stack | Python (FastAPI + uvicorn + PyQt6), PyInstaller ile tek exe |
| İndirme motoru | aria2c.exe (gömülü, RPC modu, parçalı indirme + devam) |
| Video çözücü | yt-dlp.exe (gömülü, sadece link çözer, indirme YAPMAZ) |
| Arayüz | IDM tarzı mini yüzen pencere (~420×360), sistem tepsisi ikonu, hep açık |
| Video indirme | v1 kapsamında |
| Sunucu | Yalnız 127.0.0.1'e bağlanır (dış erişim imkansız) |
| Port stratejisi | Açılışta kontrol; doluysa 8766, 8767... sıradaki boş porta geçer |

## 2. Mimari

```
AI (herhangi biri)
   │  POST http://127.0.0.1:8765/indir   {link, kimlik}
   ▼
KÖPRÜ (FastAPI, port 8765)
   1. Link türü: video sitesi mi? → yt-dlp çöz → düz link + başlık + boyut
      değilse → olduğu gibi
   2. Politika: >2GB ise "onay bekliyor" durumuna al
   3. aria2 RPC (port 6800) addUri → kuyruk
   ◄── cevap: {durum: kabul|beklemede|reddedildi, neden?}
        ▲                       ▲
PENCERE (PyQt6) ────────────────┘
  aria2 RPC tellStatus ile liste/%/hız okur (1 sn polling)
  kullanıcı aksiyonu → aria2 RPC pause/unpause/remove
  hız limiti → aria2 RPC globalSpeedLimit
```

**Kritik ilke:** yt-dlp asla indirmez; tüm indirme aria2'den geçer → durdur/devam/hız
her içerik türü için aynı şekilde çalışır. Pencere tek kaynaktan (aria2) okur.

## 3. Pencere Düzeni
- **Üst şerit:** başlık + menü (☰) + pencere kontrolleri
- **Liste satırı:** solda link (orta kesik: `youtube.com/…xyz123`), sağda `%47 + 2.1 MB/s`
- **Renkler:** yeşil=indiyor, sarı=duraklatıldı, kırmızı=hata, gri ✔=bitti
- **Tek tık:** satırın altında aksiyon şeridi açılır (`▶ Devam / ⏸ Durdur / ✖ İptal`);
  başka satıra tıklayınca eski kapanır. Çift tık: klasörde göster.
- **Menü (☰):** Maksimum hız (sınırsız/1/5/10/25/50 MB/s + özel) • her zaman üstte,
  başlangıçta çalıştır • bağlantı bilgisi (AI'lar için hazır kod parçaları) • indirilenler
  klasörü
- **Alt şerit:** aktif indirme sayısı • toplam hız • kalan toplam boyut

## 4. API Sözleşmesi
- **Adres:** `http://127.0.0.1:8765/indir` (port doluysa tool'un bulduğu port; menüde gösterilir)
- **İstek:** `{ "link": "https://...", "kimlik": "kimi" }`
- **Cevaplar:**
  - `200 {durum: "kabul", id: "..."}` → kuyruğa eklendi
  - `200 {durum: "beklemede", sebep: "2GB üstü onay bekliyor"}` → pencerede onaylanınca başlar
  - `400 {durum: "reddedildi", sebep: "..."}` → link çözülemedi / geçersiz
- Menüdeki "bağlantı bilgisi" ekranı: her AI için kopyala-yapıştır hazır 5 satırlık kod.

## 5. Politika (v1)
Tek kural: **2GB üstü dosyalar AI'dan gelse bile "onay bekliyor" durur**, kullanıcı
pencereden onaylayana kadar inmez. (Kural altyapısı genişletilebilir; v1'de sadece bu.)

## 6. Hata Durumları
| Durum | Davranış |
| --- | --- |
| İnternet koptu | otomatik 3 deneme (aralıklı), sonra satır kırmızı + "yeniden dene" |
| Link ölü/geçersiz | kırmızı satır, AI'a açıklamalı cevap |
| yt-dlp çözemedi | aynı; sebep (site değişimi vb.) AI'a iletilir |
| Disk dolu | indirme durur, bildirim düşer |
| Port çakışması | açılışta tespit, sıradaki boş porta geçiş + menüde gösterim |

## 7. Test Stratejisi
1. **Pencere testi:** sahte aria2 verisiyle — liste, tıklama, hız limiti (internetsiz)
2. **İndirme testi:** gerçek aria2 + yerel dosya sunucusu (localhost'tan localhost'a, internet gerekmez)
3. **Uçtan uca:** gerçek video sitesi → çöz → in → durdur → devam → iptal

## 8. Kapsam Dışı (v1 sonrası)
Tarayıcı video yakalama (IDM'in sayfadan video koklaması) • buluta/yazıcıya gönderme •
indirme zamanlama • çoklu kullanıcı/parola. Bunlar fikir olarak not edildi, v1'e girmiyor.

## 9. Dağıtım
PyInstaller → tek `ai-dl-bridge.exe` (aria2c + yt-dlp gömülü). Windows v1;
Linux/macOS aynı koddan derlenebilir (PyQt6 cross-platform) ama v1'de test edilmez.

## 10. Teslim Kriteri
AI (herhangi biri) link gönderir → pencerede listelenir → kullanıcı durdurur/devam
ettirir/iptal eder → hız limiti uygulanır → bittiğinde dosya hedef klasörde → hata
durumları spec'teki gibi davranır → 3 katmanlı testler yeşil.
